# Changelog

## Unreleased

- Added the `coalesce` image loader, which gathers organic fragments into a unified image plane.
- Added four image-generation loaders: `diffusion`, `contour`, `raster`, and `bloom`.

## 0.1.1

- Added the `count-up` inline loader, which displays every integer from 0 through 100.
- Reduced the image-loader collection to eight variants.
- Expanded package documentation, support links, and ownership metadata.

## 0.1.0

- Initial text collection with sixteen streaming and reveal patterns.
- Append-only streaming preserves stable output while each newly received chunk animates.
- Fourteen compact inline activity indicators for buttons and status rows.
- Nine square image-generation placeholders with configurable size and radius.
- Custom copy, color, speed, pause, size, and accessible labels.
- SSR-safe Framer Motion rendering with accessible and reduced-motion output.
